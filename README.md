# Hack of the Week

Material from the Hack of the Week block of the CSCG group meeting: short demos of how to use agentic AI in research.

| Folder | What it is |
|---|---|
| [`mock-exam/`](mock-exam/) | Pilot a new exam on simulated students. Persona agents sit it, blind graders mark it, analysts propose edits, and a live dashboard shows the run. From the subagents session. |

Each folder is its own Claude Code project. Open Claude Code inside the folder (for example `cd mock-exam && claude`) so that its agents, workflows and hooks load.
